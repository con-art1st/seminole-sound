# Project 1 Starter — Seminole Sound 91.5

CGS 3066 · Web Programming & Design · Florida State University

## What's in here

```
seminole-sound/
├── index.html        header + nav written for you, page body is TODOs
├── schedule.html     empty shell
├── request.html      empty shell
├── join.html         empty shell
└── images/           placeholder art — you may ship it as-is
```

That's the whole project. Four HTML pages and a folder of images.

**No audio or video files.** Do not add an `.mp3`, `.mp4`, or any other media
file to your submission. Images and one map embed are the only non-text
assets this project uses.

## How to start

1. Unzip this folder somewhere you'll remember. Don't work inside the zip.
2. Open `index.html` in a text editor **and** in a browser side by side.
3. Work through the `TODO` comments in `index.html` first — it establishes the
   header, nav and footer you'll reuse on every other page.
4. Then do `schedule.html`, `request.html`, `join.html` in any order.
5. Delete each `TODO` comment as you satisfy it. Leftover TODOs in a submitted
   project read as unfinished work.

## Before you submit

- [ ] Every page validates at https://validator.w3.org/#validate_by_upload with **zero errors**
- [ ] Exactly one `<h1>` per page, no skipped heading levels
- [ ] Every `<img>` has alt text that describes the image
- [ ] Every form control has a `<label for="...">` matching its `id`
- [ ] The map `<iframe>` has a `title`
- [ ] The nav is byte-for-byte identical on all four pages
- [ ] No `<style>` blocks, no `style=` attributes, no `<script>` — this project is markup only
- [ ] No `.mp3`, `.mp4`, or other media files anywhere in the folder
- [ ] You opened the site from the unzipped folder and clicked every nav link

## Notes

- The placeholder images name what they stand in for and carry their pixel
  dimensions, so you can drop in real art at the same size. Shipping them
  as-is is fine and costs you nothing.
- If you do replace them, use royalty-free sources (unsplash.com,
  placehold.co) and keep them inside `images/`.
- For the map on the home page, use Google Maps' **Share → Embed a map**
  feature. Google's embed code does not include a `title` attribute — add one.
- Use **relative** paths only. `C:\Users\you\Desktop\...` will not work on the
  grader's machine.
